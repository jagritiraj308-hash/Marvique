HOW TO RUN
==========

Step 1:
Open the project folder in Visual Studio Code.

Step 2:
Install the "Live Server" extension in VS Code.

Step 3:
Open the file:

index.html

Step 4:
Right-click on index.html.

Step 5:
Select:

"Open with Live Server"

The website will open automatically in your browser.


IMPORTANT
=========

Do NOT open index.html directly by double-clicking the file.

This project uses JavaScript fetch() to load HTML files
from the sections folder.

Therefore, the project should be run using Live Server
or another local HTTP server.


CUSTOMIZATION
=============

You can change the following information:

1. Business Name
   Search for:
   MARVIQUE

2. Phone Number
   Search for:
   +91 XXXXX XXXXX

3. Email
   Search for:
   info@marvique.com

4. Showroom Address
   Search for:
   Your Showroom Address

5. Images
   Background images can be changed inside the CSS files.

6. Colors
   Main colors can be changed inside:

   css/base.css

   Example:

   --gold: #c8a96b;
